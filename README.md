# Web-Security-Notes

A personal collection of my notes, findings, and write-ups while learning web security.

I use this repository to document what I learn from labs, CTFs, and practical experiments — including vulnerabilities, techniques, HTTP behavior, and things I discover while solving problems.

The goal isn't to collect solutions, but to understand why something works, how I found it, and what I learned from it.

Learning by breaking things, understanding why they break, and documenting the process.
